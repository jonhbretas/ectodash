**Phase goal (per ROADMAP.md):** Volunteers and leaders are automatically reminded by email about approaching and overdue demandas, with reliable, traceable delivery.

This plan is Wave 3 — the phase's closing wave, doing the one thing no earlier wave could: putting the cron route to work in production, and giving the coordenador a visible run log (LEMB-04) on the existing `/painel` dashboard. Purpose: close the one deployment gap this phase's own research explicitly flagged as a required, non-optional new step (not a silent assumption folded into "deploy"), and make LEMB-04's "visível" requirement literally true for the coordenador, not just true in the database.
